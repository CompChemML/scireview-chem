============================================================
SCIREVIEW CHEM
Systematic Literature Review & Evidence Synthesis Workbench
============================================================

PURPOSE

SciReview Chem is a scientific research application for:

- chemistry
- materials science
- environmental science
- nanotechnology
- toxicology
- cheminformatics
- chemical regulatory research
- pharmaceutical and life-science literature
- scientific consulting

Its purpose is to help a researcher or scientific freelancer conduct a
transparent and reproducible literature-review workflow from:

RESEARCH QUESTION
      ↓
SEARCH STRATEGY
      ↓
REFERENCE IMPORT
      ↓
DEDUPLICATION
      ↓
TITLE / ABSTRACT SCREENING
      ↓
FULL-TEXT SCREENING
      ↓
DATA EXTRACTION
      ↓
QUALITY / BIAS ASSESSMENT
      ↓
EVIDENCE TABLE
      ↓
PRISMA FLOW
      ↓
EVIDENCE SYNTHESIS
      ↓
REPORT / EXPORT

This project is intended primarily as:

1. a professional scientific freelancing portfolio project,
2. a practical local tool for future Kolabtree / Upwork work,
3. a research workflow assistant,
4. a foundation for more advanced evidence-synthesis software later.

It is NOT intended to automatically replace scientific judgment.

12. DEDUPLICATION ENGINE
============================================================

Implement transparent deduplication.

Use strongest identifiers first:

1. DOI exact match
2. PMID exact match
3. normalized title exact match
4. fuzzy-title match
5. title + year + first author similarity

Do NOT automatically delete uncertain duplicates.

Classify potential duplicates approximately as:

- Confirmed duplicate
- Likely duplicate
- Possible duplicate
- Unique

Allow human confirmation.

Record B

similarity score
reason for match

Allow:

possible duplicates

30. CITATION INTEGRITY
============================================================

Mandatory rules:

1. Never create a citation that is not present in the imported dataset.
2. Never invent DOI values.
3. Never create authors.
4. Never guess a journal name.
5. Never replace missing metadata with plausible text.
6. Keep a clear distinction between imported metadata and user-entered information.
7. Preserve original titles.
8. Record metadata edits.
9. If bibliographic data conflict, flag the conflict.
10. Never create fake references in generated reports.

31. SCREENING INTEGRITY
============================================================

Mandatory principles:

- Exclusions must be traceable.
- Full-text exclusions need reasons.
- Uncertain studies remain uncertain until reviewed.
- Software must not decide scientific eligibility autonomously.
- Reviewer decisions must remain editable.
- Raw imported records must remain preserved.
- PRISMA counts must derive from decisions.

Systematic Review:
